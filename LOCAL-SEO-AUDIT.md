## Measure results and decide what to publish next

- **First week:** record the launch date, whether each priority URL is indexed, the selected canonical, and the Business Profile verification status. Take an initial Search Console export as soon as data appears. No invented historical baseline. For Maps distinguish branded name searches from discovery searches.
- **Every 28 days:** export Search Console clicks, impressions, CTR and average position for **Web**, US and mobile, then compare equal periods. Page regex for the organic home and guides: `^https://evankrealestate\.com/($|areas/|guides/)`. City query regex: `(?i)(brentwood|pleasanton|livermore|walnut creek|discovery bay|oakley)`. Run a separate exact-intent filter such as `(?i)(brentwood.*(agent|realtor)|(agent|realtor).*brentwood)`. Also review city-less queries on those pages and branded “Evan / Karwowski” separately. Use city filters on query text, not as evidence of searcher location. Average position is an aggregate, not a fixed Maps or neighborhood ranking. [Search Console performance reporting](https://support.google.com/webmasters/answer/7576553).
- **Track people, not just queries:** record website inquiries by named guide and city; in FUB tally actual conversations, qualified opportunities and appointments separately. One existing contact can submit again. Keep paid/campaign traffic out of organic totals. A form note does not identify an anonymous Google search query. In [Business Profile performance](https://support.google.com/business/answer/9918094), track website and call-button clicks; a call click does not prove an answered call. Once verified, an optional profile website link ending in `?utm_source=google&utm_medium=organic&utm_campaign=business_profile` separates tagged Maps referrals in existing inquiry notes.
- **At 60–90 days:** if a URL is absent, check crawl/index status and selected canonical first. If it earns impressions but few clicks, compare the actual result and the first screen to the query before changing its title. If it gets clicks without inquiries, try a clearer city-specific offer. If homeowners regularly ask one question, turn the real answer into the next guide. Good candidates: a Discovery Bay dock-document checklist or a Walnut Creek condo-document comparison, with original observations and official sources. Add a dated market report only if the figures are licensed, attributable and have a defined geography, period and sample. Avoid automated monthly rewrites.
- **Separate Maps from ordinary results:** proximity limits how widely a Brentwood practitioner can appear in local map results. The other city guides can compete for ordinary web results independently. Google describes local visibility in terms of relevance, distance and prominence; nobody can buy or promise a first-place local ranking. [Google on local rankings](https://support.google.com/business/answer/7091).

A perfect SEO basics score coexisted with the wrong canonical host, weak local positioning and no verified Google accounts. It is not a ranking forecast.
